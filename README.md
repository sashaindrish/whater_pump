# WaterChlorinator — система автоматического хлорирования воды

Прошивка для **Arduino Nano** (ATmega328P), которая по показаниям датчика давления **PT-506** управляет насосом-дозатором хлора. Значение давления фильтруется **одномерным фильтром Калмана** и выводится в **последовательный плоттер Arduino IDE 2.x**. Все параметры настраиваются через **UART** и хранятся в **EEPROM**.

## Возможности

- 📈 Линеаризация сигнала датчика давления **4–20 мА** через измерительный резистор **220 Ом**.
- 🧮 Одномерный **фильтр Калмана** для подавления шума АЦП и плавного графика.
- 🚰 **Автоматическое управление насосом** по давлению с задержкой включения.
- ⏱ Защита по **максимальному времени работы** насоса (по умолчанию 5 с).
- 🛑 Защита от **сухого хода** — аварийный нижний порог давления.
- 💾 Хранение всех настроек в **EEPROM** (не теряются при перезагрузке).
- 🖥 Настройка через **UART** командами вида `L=2.5`, `H=4.0`, `D=100`, `M=5000`…
- 📊 Вывод в **последовательный плоттер Arduino IDE 2.x** (давление + состояние насоса).

## Аппаратная часть

### Схема подключения

```
                   +12 В (питание датчика PT-506)
                     │
                     │
              ┌──────┴──────┐
              │   PT-506    │
              │  (4–20 мА)  │
              └──────┬──────┘
                     │  ток
                     │
              ┌──────┴──────┐
              │  220 Ом 1%  │◄──── A0 (Arduino Nano)
              └──────┬──────┘
                     │
                    GND ─────── GND (Arduino Nano)

   Насос:  D2 (Arduino) ──► реле / MOSFET ──► насос-дозатор хлора
```

- Измерительный резистор **220 Ом** включён между выходом датчика и GND.
- Напряжение снимается с резистора и подаётся на **A0**.
- Питание датчика **12 В** (уточните по документации; для некоторых модификаций PT-506 требуется **24 В**).
- Пин **D2** управляет насосом через реле или MOSFET. `HIGH` — насос включён.

### Список компонентов

| Компонент | Назначение |
|---|---|
| Arduino Nano | Контроллер |
| PT-506 | Датчик давления 4–20 мА, 0–10 бар |
| Резистор 220 Ом (1%) | Преобразование тока в напряжение |
| Реле / MOSFET-модуль | Коммутация насоса |
| Блок питания 12 В | Питание датчика |
| Конденсатор 0.1 мкФ | Фильтрация ВЧ-шумов (опционально, параллельно резистору) |
| Стабилитрон 5.1 В | Защита входа A0 (опционально) |

## Принцип работы

### Преобразование сигнала датчика

Датчик PT-506 — токовый, диапазон **4–20 мА** соответствует давлению **0–10 бар**.

1. **Ток → напряжение** на резисторе 220 Ом:
   - `4 мА → 0.88 В`
   - `20 мА → 4.40 В`

2. **Напряжение → АЦП** (0–1023 при 5 В):
   - `0.88 В → ~180`
   - `4.40 В → ~900`

3. **АЦП → напряжение:**
   ```
   voltage = adc × (5.0 / 1023.0)
   ```

4. **Напряжение → ток (мА):**
   ```
   current_mA = (voltage / 220.0) × 1000.0
   ```

5. **Ток → давление (бар):**
   ```
   pressureBar = (current_mA − 4.0) × (10.0 / 16.0)
   ```

6. Ограничение: `[0 … 10] бар`.

### Фильтр Калмана

Используется **одномерный (скалярный) фильтр Калмана** с моделью «постоянное состояние»:

| Шаг | Формула |
|---|---|
| Прогноз состояния | `x_pred = x_est` |
| Прогноз ковариации | `P_pred = P_est + Q` |
| Коэффициент Калмана | `K = P_pred / (P_pred + R)` |
| Обновление оценки | `x_est = x_pred + K × (z − x_pred)` |
| Обновление ковариации | `P_est = (1 − K) × P_pred` |

- **Q** — шум процесса (доверие к модели, отвечает за скорость адаптации).
- **R** — шум измерения (доверие к датчику, отвечает за сглаживание).

Начальные значения: `Q = 0.01`, `R = 0.1`. Подбираются опытным путём.

### Автомат управления насосом

```
                lowPressure                turnOnDelay
      OFF ───────────────────► TURN_ON_DELAY ──────────► ON
       ▲                            │                     │
       │                       !lowPressure          high │  maxRunTime / emergencyLow
       │                            │                     │
       └────────────────────────────┘                     ▼
                                                  EMERGENCY_STOP
                                                        │
                                                   cooldownTime
                                                        │
                                                        ▼
                                                       OFF
```

**Состояния:**

| Состояние | Описание |
|---|---|
| `OFF` | Насос выключен, ожидание падения давления ниже `lowPress` |
| `TURN_ON_DELAY` | Задержка `turnOnDelay` мс перед включением; отменяется, если давление восстановилось |
| `ON` | Насос работает; следятся таймаут работы и аварийный нижний порог |
| `EMERGENCY_STOP` | Аварийное отключение; выжидание `cooldownTime` мс, затем `OFF` |

## Установка и сборка

1. Установите **Arduino IDE 2.x**.
2. Склонируйте или скопируйте папку `WaterChlorinator` в директорию скетчей Arduino:
   - Windows: `Документы/Arduino/`
   - Linux/macOS: `~/Arduino/`
3. Откройте `WaterChlorinator.ino` в IDE.
4. Выберите плату: **Tools → Board → Arduino Nano**.
5. Выберите процессор: **Tools → Processor → ATmega328P** (или *Old Bootloader*, если плата старая).
6. Выберите порт: **Tools → Port → COMx**.
7. Нажмите **Upload** (→).

Дополнительных библиотек устанавливать не нужно — всё встроенное (`EEPROM`, `Arduino.h`).

## UART-команды настройки

Отправляйте команды через **Serial Monitor** (скорость **9600**, перевод строки `New Line`). Каждая команда завершается символом `\n`.

| Команда | Параметр | Пример |
|---|---|---|
| `L=<float>` | Нижний порог включения, бар | `L=2.5` |
| `H=<float>` | Верхний порог выключения, бар | `H=4.0` |
| `D=<uint>`  | Задержка включения, мс | `D=100` |
| `M=<uint>`  | Макс. время работы, мс | `M=5000` |
| `C=<uint>`  | Cooldown после аварии, мс | `C=3000` |
| `E=<float>` | Аварийный нижний порог, бар | `E=0.8` |
| `show`      | Показать текущие настройки | `show` |
| `save`      | Принудительно сохранить в EEPROM | `save` |

**Пример сессии:**
```
L=1.8
L = 1.800
H=3.5
H = 3.500
D=200
D = 200.000
show
=== ТЕКУЩИЕ НАСТРОЙКИ ===
L (нижний порог, бар): 1.80
H (верхний порог, бар): 3.50
D (задержка, мс): 200
M (макс. время, мс): 5000
C (cooldown, мс): 3000
E (аварийный порог, бар): 0.80
=========================
```

Настройки сохраняются в EEPROM автоматически при каждой установке.

## Параметры по умолчанию

| Параметр | Значение | Пояснение |
|---|---|---|
| `lowPress` | **2.0 бар** | Давление, при котором включается насос |
| `highPress` | **4.0 бар** | Давление, при котором насос выключается |
| `turnOnDelay` | **100 мс** | Задержка перед включением |
| `maxRunTime` | **5000 мс** | Максимальное время работы (авария) |
| `cooldownTime` | **3000 мс** | Пауза после аварии |
| `emergencyLowPress` | **0.8 бар** | Защита от сухого хода |
| `Q` (Калман) | **0.01** | Шум процесса |
| `R` (Калман) | **0.1** | Шум измерения |

Значения записываются в EEPROM при **первом** запуске (если EEPROM «чистая»). Далее используются текущие сохранённые.

## Отображение в плоттере

1. Откройте **Tools → Serial Plotter** (или нажмите иконку графика в правом верхнем углу IDE 2.x).
2. Установите скорость **9600** (внизу окна плоттера).
3. Каждые 50 мс выводятся два числа через пробел:

   ```
   <давление, бар> <состояние насоса, 0/1>
   ```

   Пример:
   ```
   2.35 0
   2.34 0
   2.36 1
   2.41 1
   2.55 1
   ```

4. Плоттер автоматически построит **две линии**:
   - 🔵 Давление (бар)
   - 🔴 Состояние насоса (0 — выкл, 1 — вкл)

**Совет:** не открывайте одновременно Serial Monitor и Serial Plotter — они конкурируют за один COM-порт.

## Настройка фильтра Калмана

Если график слишком шумный или слишком инерционный, отредактируйте `setup()` основного скетча:

```cpp
void setup() {
  // ...
  sensor.setKalmanQ(0.01f);   // больше Q → быстрее адаптация, больше шума
  sensor.setKalmanR(0.1f);    // больше R → сильнее сглаживание, больше инерции
  // ...
}
```

| Наблюдение | Рекомендация |
|---|---|
| График «дрожит» | Уменьшить `Q` (например, 0.001) или увеличить `R` (0.3–0.5) |
| График «отстаёт» от резких скачков | Увеличить `Q` (0.05–0.1) или уменьшить `R` (0.05) |
| Готовое сбалансированное решение | `Q = 0.01`, `R = 0.1` |

## Аварийные режимы

Насос переходит в `EMERGENCY_STOP` в двух случаях:

1. **Превышено максимальное время работы** (`maxRunTime`, по умолчанию 5 с).  
   Возможная причина — негерметичность, отсутствие потока, засорение линии.

2. **Давление ниже аварийного порога** (`emergencyLowPress`, по умолчанию 0.8 бар).  
   Защита от сухого хода — насос не должен работать без воды.

В обоих случаях:
- Насос немедленно отключается.
- В Serial выводится сообщение `[PUMP] Авария: ...`.
- Система выжидает `cooldownTime` мс.
- После cooldown автомат переходит в `OFF` и готов к новому циклу.
