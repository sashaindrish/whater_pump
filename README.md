# WaterOzonation — система автоматического озонирования воды

Прошивка для **Arduino Nano** (ATmega328P) на базе **PlatformIO**, которая по показаниям датчика давления **PT-506** управляет помпой-дозатором и генератором озона. Давление фильтруется **одномерным фильтром Калмана**, все параметры хранятся в **EEPROM** и настраиваются через **UART**. Данные выводятся в **последовательный плоттер**.

Проект создан для обработки воды из скважины с примесями **двухвалентного железа (Fe²⁺)** и **сероводорода (H₂S)**. Озон окисляет их до нерастворимых форм, которые затем удаляются механическим фильтром.

## Возможности

- 📈 Линеаризация сигнала датчика давления **4–20 мА** через резистор **220 Ом**.
- 🧮 Одномерный **фильтр Калмана** для подавления шума АЦП.
- 🚰 **Подача озона по падению давления**: помпа и озонатор включаются, когда давление падает ниже порога.
- ⏱ **Ограничение подачи** 15 с и пауза 45 с — защита помпы и генератора озона.
- 🛑 **Досрочная остановка**, если давление продержалось выше порога 2 секунды.
- 💾 Хранение настроек в **EEPROM** с маркером валидности.
- 🖥 Настройка через **UART** (3 параметра).
- 📊 Вывод в **последовательный плоттер** (давление + состояние).

## Аппаратная часть

### Схема подключения

```
                   +12 В (питание датчика PT-506)
                     │
              ┌──────┴──────┐
              │   PT-506    │
              │  (4–20 мА)  │
              └──────┬──────┘
                     │  ток
              ┌──────┴──────┐
              │  220 Ом 1%  │◄──── A0 (Arduino Nano)
              └──────┬──────┘
                     │
                    GND ─────── GND (Arduino Nano)

   Реле:  D2 (Arduino) ──► реле ──┬── помпа-дозатор
                                  └── генератор озона
```

- Измерительный резистор **220 Ом** включён между выходом датчика и GND.
- Напряжение снимается с резистора и подаётся на **A0**.
- Питание датчика — **12 В** (уточните по документации; некоторые PT-506 требуют 24 В).
- Пин **D2** управляет реле, на котором одновременно **помпа и озонатор**. `HIGH` — работа.

### Список компонентов

| Компонент | Назначение |
|---|---|
| Arduino Nano | Контроллер |
| PT-506 | Датчик давления 4–20 мА, 0–10 бар |
| Резистор 220 Ом (1%) | Преобразование тока в напряжение |
| Реле-модуль | Коммутация помпы и озонатора |
| Блок питания 12 В | Питание датчика |
| Конденсатор 0.1 мкФ | Фильтрация шумов (опционально) |
| Обратный клапан | Защита озонатора от воды |

## Принцип работы

### Преобразование сигнала датчика

1. **Ток → напряжение** на резисторе 220 Ом:
   - `4 мА → 0.88 В`
   - `20 мА → 4.40 В`
2. **Напряжение → АЦП** (0–1023 при 5 В).
3. **АЦП → напряжение**: `V = adc × 5 / 1023`.
4. **Напряжение → ток**: `I = V / 220 × 1000` (мА).
5. **Ток → давление**: `P = (I − 4) × 10 / 16` (бар).
6. Ограничение: `[0 … 10] бар`.
7. **Фильтр Калмана** сглаживает шум АЦП.

### Химия процесса

| Загрязнитель | Реакция с озоном | Продукт |
|---|---|---|
| **Fe²⁺** | `2Fe²⁺ + O₃ + 5H₂O → 2Fe(OH)₃↓ + O₂ + 4H⁺` | Бурый осадок — удаляется фильтром |
| **H₂S** | `H₂S + O₃ → S↓ + O₂ + H₂O` (малая доза) | Сера / сульфат — без запаха |
| Бактерии | Окисление мембран | Инактивация |

## UART-команды настройки

Скорость **9600**, перевод строки `New Line`. Каждая команда завершается `\n`.

| Команда | Параметр | Пример |
|---|---|---|
| `P=<float>` | Порог старта, бар | `P=3.0` |
| `O=<uint>`  | Время подачи, мс | `O=15000` |
| `F=<uint>`  | Пауза между подачами, мс | `F=45000` |
| `show`      | Показать настройки | `show` |
| `save`      | Сохранить в EEPROM | `save` |
| `R`         | Сбросить к значениям по умолчанию | `R` |

**Пример сессии:**
```
show
=== НАСТРОЙКИ ОЗОНИРОВАНИЯ ===
P startPress, бар: 3.00
O onTime, мс: 15000
F offTime, мс: 45000
==============================

P=2.5
P = 2.500

R
Настройки сброшены к значениям по умолчанию.
=== НАСТРОЙКИ ОЗОНИРОВАНИЯ ===
P startPress, бар: 3.00
O onTime, мс: 15000
F offTime, мс: 45000
==============================
```

Настройки сохраняются в EEPROM автоматически при каждой установке.

## Параметры по умолчанию

| Параметр | Значение | Пояснение |
|---|---|---|
| `startPress` | **3.00 бар** | Давление, при котором запускается подача озона |
| `onTime` | **15000 мс** | Максимальное время подачи |
| `offTime` | **45000 мс** | Пауза между подачами |
| `STOP_HOLD_MS` | **2000 мс** | Удержание давления выше порога для остановки |
| `Q` (Калман) | **0.005** | Шум процесса |
| `R` (Калман) | **0.15** | Шум измерения |

## Отображение в плоттере

Каждые 50 мс выводятся три числа через пробел:

```
<давление, бар> <реле 0/1> <состояние 0..2>
```

Пример:
```
2.35 0 0     ← IDLE
2.20 0 0
1.85 1 1     ← RUN
1.50 1 1
1.20 1 1
3.10 0 2     ← COOLDOWN
3.30 0 2
```

- 🔵 Давление (бар)
- 🟢 Реле (0 — выкл, 1 — вкл)
- 🔴 Состояние (0 — IDLE, 1 — RUN, 2 — COOLDOWN)

Откройте **PlatformIO: Serial Monitor** или **Arduino IDE → Serial Plotter**, скорость **9600**.

## Алгоритм работы

```
   IDLE ──(P ≤ startPress)──► RUNNING
                                │
                    ┌───────────┴───────────┐
                    │                       │
        (P > startPress непрерывно      (onTime истёк)
            в течение 2 с)
                    │                       │
                    ▼                       ▼
               COOLDOWN ◄─────────────────┘
                    │
              (offTime истёк)
                    │
                    ▼
                  IDLE
```

| Состояние | Что делает |
|---|---|
| `IDLE` | Реле выключено, ждём падения давления до `startPress` |
| `RUNNING` | Реле включено. Работает до одного из событий: давление выше порога 2 с, либо истёк `onTime` |
| `COOLDOWN` | Реле выключено. Ждём `offTime`, потом снова `IDLE` |

**Диагностика в Serial:**

```
[OZ] Старт подачи
[OZ] Стоп (P>порога 2.0 с). Работа 5.0 с
[OZ] Готов к новой подаче
[OZ] Стоп (таймаут). Работа 15 с
```

## Настройка фильтра Калмана

Параметры задаются в `setup()` файла `src/main.cpp`:

```cpp
sensor.setKalmanQ(0.005f);   // шум процесса
sensor.setKalmanR(0.15f);    // шум измерения
```

| Наблюдение | Рекомендация |
|---|---|
| График «дрожит» | Уменьшить `Q` (0.001) или увеличить `R` (0.3) |
| График «отстаёт» от скачков | Увеличить `Q` (0.05) или уменьшить `R` (0.05) |
| Сбалансированно | `Q = 0.005`, `R = 0.15` |

## Отладка и тесты

### Отладка логики в симуляторе (Windows)

1. Выберите окружение `simavr`.
2. Поставьте точку останова в `OzonationController.cpp`.
3. Нажмите **F5** — запустится `simavr` с GDB.
4. Используйте панель отладки VSCode (`Step Over`, `Variables`, `Watch`).

### Native-тесты (Linux/macOS)

```bash
pio test -e native
```

Пример структуры теста в `test/test_ozonation/test_main.cpp`:

```cpp
#include <unity.h>
#include "OzonationController.h"

Config cfg;
OzonationController *oz;

void setUp() {
    cfg.startPress = 1.0f;
    cfg.onTime     = 15000;
    cfg.offTime    = 45000;
    oz = new OzonationController(2);
    oz->begin();
}

void tearDown() { delete oz; }

void test_starts_on_low_pressure() {
    oz->update(0.5f, cfg);
    TEST_ASSERT_EQUAL(OZ_RUNNING, oz->getState());
}

void test_stops_on_timeout() {
    oz->update(0.5f, cfg);
    delay(cfg.onTime + 50);
    oz->update(0.5f, cfg);
    TEST_ASSERT_EQUAL(OZ_COOLDOWN, oz->getState());
}

int main(int argc, char **argv) {
    UNITY_BEGIN();
    RUN_TEST(test_starts_on_low_pressure);
    RUN_TEST(test_stops_on_timeout);
    return UNITY_END();
}
```

### Настройка EEPROM

При первом запуске, если в EEPROM нет маркера `0xA5C3`, автоматически загружаются значения по умолчанию. Если данные повреждены (`NaN`, отрицательные значения, слишком большие таймауты) — тоже сбрасываются. Ручной сброс — команда `R`.
